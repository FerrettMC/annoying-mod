-CHANGE MOD ID TO AN ACTUAL MOD ID (ALL LOWERCASE, NO SPACES)
IN ("ExampleMod.java", "gradle.properties")

-IN "/resources/META-INF/mods.toml", CHANGE MOD NAME TO A READABLE NAME, CHANGE
LICENSE TO MIT, MOD VERSION (OPTIONAL), AUTHORS AND DESCRIPTION

-CLICK ELEPHANT DUDE (Gradle) ON THE RIGHT AND "Sync All Gradle Projects"

-BUILD PROJECT

-CLICK Gradle, Tasks, slimelauncher, and run "runClient"

-Happy modding!
